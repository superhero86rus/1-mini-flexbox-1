```txt
display: flex - включаем флекс

flex-direction - задаем направление основной оси

flex-wrap - перенос айтемов в случае достижения границы экрана (по дополнительно оси)
* { box-sizing: border-box; } - растягиваем

flex-flow: row nowrap; Одно свойство вместо flex-direction + flex-wrap

Позиционирование внутри контейнера:
justify-content - распределение по основной оси
align-items - распределение по дополнительно оси (только для конкретной строки)
align-content - выстраивание поведения по дополнительной оси

align-self - может позиционировать конкретный элемент по дополнительной оси

margin-left/right/top/bottom: auto - позволяет отбить элемент(ы) в конец контейнера

flex:2 - задаем пропорции элемента (в данном вслучае элемент будет в 2 раза больше других)

gap - отступы (gap: 20px 10px; горизонтальный отступ 20px, вертикальный 10px)
```

```txt
FLEX или flex-basic/flex-shrink/flex-grow

flex-basis:300px - займем базовую шируну, даже если есть пространство справа;

Работают в рамках одной строки:
flex-grow:2 - сколько частей свободного пространства может занять элемент
flex-shrink:5 - насколько сильнее сжать элемент (в 5 раз) относительно другого

Вместо этого всего можно записать:
flex 1 1 300px - flex-grow:1 flex-shrink-1 flex-basis:300px;
```
